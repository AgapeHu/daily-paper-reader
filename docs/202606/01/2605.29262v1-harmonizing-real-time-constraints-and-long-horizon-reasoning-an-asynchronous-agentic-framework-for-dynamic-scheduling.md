## 摘要
动态柔性作业车间调度问题需要在随机扰动的即时响应与生产目标的全局优化之间进行权衡。传统优先级规则灵活度不足，难以应对复杂扰动，而基于学习的方法往往牺牲可解释性，或难以在不同问题规模上泛化。尽管大语言模型具备高级推理能力可弥合这一差距，但其显著的推理延迟与工业控制系统的毫秒级决策周期不兼容。为解决这一冲突，我们提出了RACE-Sched，一种基于异步智能体的框架，通过双流架构将策略执行与逻辑推理解耦。反应流执行低延迟的符号启发式规则以实现实时调度，而并行的深思流利用大语言模型合成、验证并演化这些规则。候选规则在沙盒中经过严格测试，并通过原子更新部署，确保安全且不阻塞控制回路。此外，语义规则库为基于检索的初始化索引已验证的启发式规则，增强了跨问题规模的迁移能力。在GEN-Bench、MK-Bench和JMS-Bench上的广泛评估表明，RACE-Sched优于领先的深度强化学习及其他基于大语言模型的基线方法。该方法协调了实时约束与长期推理，实现了更优的解质量和对动态事件的鲁棒适应。

## Abstract
The Dynamic Flexible Job Shop Scheduling Problem (DFJSP) necessitates a trade-off between instant reaction to stochastic disturbances and global optimization of production goals. Conventional priority rules are insufficiently flexible to handle complex disruptions, whereas learning-based approaches often compromise interpretability or fail to generalize across problem scales. Although Large Language Models (LLMs) offer advanced reasoning capabilities to bridge this gap, their substantial inference latency is incompatible with the millisecond-level decision cycles of industrial control systems. To resolve this conflict, we introduce RACE-Sched, an asynchronous agent-based framework that decouples policy execution from logical reasoning via a dual-stream architecture. The Reactive Stream executes low-latency symbolic heuristics to enable real-time dispatching, while the parallel Deliberative Stream leverages an LLM to synthesize, validate, and evolve these rules. Candidate rules undergo rigorous testing in a sandbox and are deployed via atomic updates, ensuring safety without blocking the control loop. Additionally, a semantic rule repository indexes validated heuristics for retrieval-based initialization which enhances transferability across problem scales. Extensive evaluations on GEN-Bench, MK-Bench, and JMS-Bench demonstrate that RACE-Sched outperforms leading Deep Reinforcement Learning and other LLM-based baselines. This approach harmonizes real-time constraints with long-horizon reasoning to achieve superior solution quality and robust adaptation to dynamic events.

  - **优先级调度规则（PDR）**：执行快、可解释，但结构固定，无法适应瓶颈动态变化。
  - **深度强化学习（DRL）**：能学习复杂策略，但决策不透明、泛化性差、离线训练后无法在线连续适应。
  - **大语言模型（LLM）**：具备高级推理和代码生成能力，但推理延迟高达数秒，无法直接嵌入工业控制循环（毫秒级）。
- **现有混合方法的局限**：大多数方法将学习与执行分离，缺乏在线安全演化机制；LLM 的直接集成会导致生产线阻塞；已有异步双流概念（如具身智能体）未考虑调度领域对可解释性和安全性约束的严格要求。
- **研究目标**：设计一个框架，既能实现实时响应，又能利用 LLM 进行长期推理和策略改进，且保证安全、可解释、可迁移。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想：异步双流架构（Asynchronous Dual-Stream Architecture）
- **反应流（Reactive Stream）**：位于控制循环内，执行低延迟符号优先级规则（Python 编译函数），决策时间 <1ms，不依赖 LLM。
- **深思流（Deliberative Stream）**：在后台异步运行，利用 LLM 合成、验证候选规则，通过原子“热插拔”更新活动规则集，不阻塞控制循环。

### 2.2 关键技术细节

#### （1）触发更新协议
- 两种触发方式：
  - **周期性触发**：每 K 个决策步骤触发一次。
  - **性能触发**：当滑动窗口内性能指标下降幅度超过阈值 ϵ 时触发。
- 深思流生成候选规则 ϕ_new，仅当沙盒验证通过后，通过原子指针交换安全部署。

#### （2）智能体循环（Agentic Loop）——安全约束演化循环
- **战略规划器（Strategic Planner）**：基于当前系统状态摘要和优化目标，生成简短策略指令（如“优先紧急作业”）。
- **语法执行器（Syntactic Enforcer）**：将策略指令转化为可执行的 Python 优先函数，约束使用标准化车间属性，保证编译安全，执行代码长度截断和危险导入限制。
- **仿真验证器（Simulation Validator）**：在沙盒中回放代表性实例，对比候选规则与旧规则在相同扰动下的性能，计算：
  - 相对改进率 r_t
  - 合并标准差 Welch t 检验
  - 仅当满足 r_t ≥ ϵ_rel、效应量 ≥ d_min 和统计显著（T_t ≥ T_α）时才接受。
- **语义反射器（Semantic Reflector）**：将沙盒评估数据转换为浓缩的诊断反馈（如解释权衡），辅助后续迭代优化，并记录轨迹。

#### （3）语义规则库（Semantic Rule Repository）
- 持久化已验证的高性能启发式规则，每个条目包含：
  - 元特征向量 m_i（作业数量、机器数量等）
  - 策略源代码 ϕ_i
  - 归一化性能提升 v_i
  - 结构复杂度分数 C_i
- **检索评分函数**：
  \[
  S(T_i|m_{\text{new}}) = v_i - \lambda_1 D(m_{\text{new}}, m_i) - \lambda_2 \log(1 + C_i) + \delta_{\text{match}}
  \]
  其中距离 D 基于作业数和机器数的归一化曼哈顿距离。
- 对新实例，检索最相似规则进行 warm-start，减少 LLM 调用和搜索空间。

#### （4）安全部署
- 所有候选规则先编译，再沙盒测试，通过后才原子交换，确保控制循环不受未经验证规则影响。

## 6. 主要结论与发现

1. **性能领先**：RACE-Sched 在 GEN-Bench Normal 上 RPD 最低达 5.33%（Qwen3-8B），较最优 DRL 基线 IDDQN（9.82%）提升 45.7%；平均排名显著优于所有基线。

3. **效率优势**：token 消耗比 LLM-Direct 降低约 60%，主要归功于规则库检索减少冗余推理，且输出从逐动作生成变为紧凑策略代码。

5. **鲁棒适应**：在机器故障压力测试中，RACE-Sched 能快速合成新规则恢复吞吐量，最终 makespan 最低（29.6），优于其他方法。
