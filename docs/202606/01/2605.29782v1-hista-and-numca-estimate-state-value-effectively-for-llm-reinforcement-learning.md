## 摘要
强化学习通过奖励信号直接优化模型行为来改进大语言模型。虽然准确的状态价值估计对于经典RL中的稳定训练至关重要，但在LLM后训练中，这一挑战仍未得到充分探索。在这项工作中，我们引入了状态价值估计基准（SVEB）来评估现有RL框架中的状态估计，并表明在PPO等标准方法中，评论家会退化为粗糙的组平均基线。为解决这个问题，我们提出了两种技术：Numca，利用数值跨度作为可分级里程碑进行状态价值估计；以及Hista，一个使用LLM隐藏状态作为表示对不相关的轨迹及其回报进行加权平均的框架。大量实验表明，两种方法都能产生更准确的状态价值估计，并在不同的RL算法和模型规模下提升训练性能，且不会带来显著的计算开销。

## Abstract
Reinforcement learning (RL) refines large language models (LLMs) by directly optimizing model behavior through reward signals. While accurate state value estimation is critical for stable training in classical RL, it remains an underexplored challenge in LLM post-training. In this work, we introduce the State Value Estimation Benchmark (SVEB) to assess state estimation within existing RL frameworks and show that critics in standard approaches like PPO collapse to a coarse group-average baseline. To address this, we propose two techniques: Numca, which leverages numerical spans as gradable milestones for state value estimation, and Hista, a framework that uses LLM's hidden states as representation to weighted average disjoint rollouts and their return. Extensive experiments demonstrate that both methods yield more accurate state value estimates and enhance training performance across different RL algorithms and model sizes without incurring significant computational overhead.

## 2. 方法论：核心思想、关键技术细节

### 2.1 Numca（数值里程碑信用分配）

- **核心思想**：受后见经验回放启发，将数学推理建模为稀疏奖励的目标到达问题，利用数值（整数、小数、分数等）作为天然可验证的里程碑子目标。
- **关键技术细节**：
  - 定义一组数值模式 \( P \)；里程碑 \( m \) 是匹配该模式的token子序列。
  - 抽象状态 \( s^M_t \) 为到时间t为止所有里程碑的集合。
  - 宏动作定义为两个连续抽象状态之间的token序列。
  - 价值估计：对于每个抽象状态 \( s^M \)，将其价值估计为所有包含该抽象状态的完整轨迹的最终奖励的平均值。
  - 实现使用字典存储计数和奖励和，计算开销极低。
- **算法流程**（文字描述）：
  1. 初始化一个空字典，用于存储每个抽象状态的（计数，奖励和）。
  2. 遍历每个轨迹（一组rollout），记录出现的里程碑序列，每遇到新抽象状态就更新字典。
  3. 遍历所有抽象状态，计算平均值作为其状态价值。

### 2.2 Hista（基于隐藏状态的状态价值估计）

- **核心思想**：利用LLM最后一层的隐藏状态作为通用状态表示，通过概率加权平均不相交轨迹的回报来估计状态价值，无需额外训练或rollout。
- **关键技术细节**：
  - **隐藏状态提取**：从完整响应（终端状态）的最后一层隐藏状态序列中，通过指数移动平均（EMA）压缩，并均匀采样位置，得到该轨迹的一组离散状态表示。
  - **MinDistance操作**：定义两个隐藏状态序列之间的最小距离（MD），并理论上证明MD与两个状态获得相同最终奖励的概率成反比（定理5.2）。
  - **价值估计**：对于当前状态，计算其与同一prompt组内所有其他状态的MD，选择k个最近邻，以其倒数为权重对邻居的最终奖励进行加权平均（公式5.2）。
  - **效率**：通过批量GPU计算，空间复杂度为 \( O(\lfloor T/d \rfloor^2) \)，实际训练步延时增加小于1秒。
- **理论保证**：定理5.5证明，在合理假设下，概率加权估计器的偏差绝对值不大于简单平均估计器（GRPO基线）。
