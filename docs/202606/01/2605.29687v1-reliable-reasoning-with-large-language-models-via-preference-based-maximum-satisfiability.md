## 摘要
大语言模型（LLM）在理解自然语言方面表现出色，但在涉及多个约束和用户定义偏好的优化任务中表现不佳，这类任务在机器人等领域很常见。我们提出了一种混合推理方法，其中LLM通过代码生成将推理外部化。给定自然语言问题描述，LLM生成Python代码，将用户定义的约束和偏好编码为基于偏好的最大可满足性（MaxSAT）问题，然后由精确的MaxSAT求解器求解。为确保正确性，模型生成代码返回的解决方案会与规范MaxSAT编码进行独立验证，检查其可行性和最优性，允许不同的编码和多个最优解。我们使用开源和闭源的LLM在三个偏好推理任务系列上评估了我们的方法，并将其与使用相同模型的直接回答、思维链和程序思维基线进行比较。尽管这些基线很少产生可行的解决方案，基于MaxSAT的流水线实现了显著更高的接受率，在某些情况下超过80%。我们的结果表明，LLM驱动的代码生成结合基于偏好的MaxSAT能够针对生成的编码实现求解器可验证的优化，并在独立验证的参考语义下大幅提高正确性。

## Abstract
Large Language Models (LLMs) excel at understanding natural language but struggle with optimisation tasks involving multiple constraints and user-defined preferences, which commonly arise in domains such as robotics. We propose a hybrid reasoning approach in which LLMs externalise reasoning through code generation. Given a natural language problem description, an LLM generates Python code that encodes user-defined constraints and preferences as a preference-based Maximum Satisfiability (MaxSAT) problem, which is then solved by an exact MaxSAT solver. To ensure correctness, solutions returned by the model-generated code are independently verified for feasibility and optimality against a canonical MaxSAT encoding, allowing for different encodings and multiple optimal solutions. We evaluate our approach using both open-source and closed-access LLMs on three families of preference-based reasoning tasks, and compare it against direct-answer, chain-of-thought, and program-of-thought baselines using the same models. While these baselines rarely produce feasible solutions, the MaxSAT-based pipeline achieves substantially higher acceptance rates, in some cases exceeding 80%. Our results demonstrate that LLM-driven code generation combined with preference-based MaxSAT enables solver-verifiable optimisation with respect to generated encodings, and substantially improves correctness under independently verified reference semantics.

- **整体含义**：论文提出一种神经符号混合方法，将 LLM 的自然语言理解与代码生成能力，同基于偏好的最大可满足性（MaxSAT）求解器的形式化优化能力相结合。核心思路是将推理“外部化”：LLM 负责将用户描述转化为可执行的 MaxSAT 编码代码，而求解器负责精确求解，并通过独立验证确保方案的可行性和最优性。该方法旨在提升 LLM 在偏好感知优化任务中的可靠性和可验证性。

## 2. 论文提出的方法论

- **核心思想**：LLM 不应被信任进行内部优化推理，但能有效将用户意图转化为代码。将推理从 LLM 中剥离，委托给符号求解器，从而获得形式化保证。

- **关键技术细节**：
  - **中间规划（Intermediate Planning）**：LLM 首先生成结构化规划（变量、硬约束、软约束/偏好、目标、输出格式），作为后续代码生成的指导。此步骤可提升编码准确性，但不强制。
  - **代码生成**：LLM 根据规划或直接根据自然语言描述，使用 PySAT API 生成 Python 代码，将问题编码为加权偏 MaxSAT 实例（硬约束：必须满足；软约束：带权重的用户偏好）。
  - **MaxSAT 求解**：调用 RC2 等精确 MaxSAT 求解器求解生成的编码，返回最优赋值。
  - **独立验证**：针对每个问题实例，预先构建一个规范 MaxSAT 编码（不提供给模型）。执行模型生成的代码后，将求解结果与规范编码进行验证：
    - **可行性**：是否满足所有硬约束。
    - **最优性**：目标代价是否等于规范最优值。允许不同编码和多个最优解被接受。
  - **反馈迭代**：若代码执行出错或违反输出格式，返回错误信息给 LLM，要求修正（最多 5 次迭代）。不暴露规范编码信息。

- **算法流程（文字描述）**：
  1. 用户输入自然语言问题描述。
  2. （可选）LLM 生成中间规划。
  3. LLM 根据规划或原始描述生成 Python 代码（使用 PySAT）。
  4. 执行代码，调用 MaxSAT 求解器得到候选解。
  5. 对候选解进行独立验证（可行性 + 最优性）。
  6. 若成功，输出可靠最优解；否则，提供非规范反馈并跳至步骤 3。

## 3. 实验设计

- **数据集**：构造了一个包含三个问题家族的偏好推理数据集，共 25 个实例 × 4 种偏好变体（none, p1, p2, p3）= 300 个测试实例。问题家族：
  - **最大独立集（MIS）**：选择最大不相邻顶点子集，软约束为惩罚选非独立顶点。
  - **调度（Scheduling）**：任务分配起始时间，满足前序和资源约束，最小化违反截止时间的加权惩罚。
  - **集合覆盖（Set Cover）**：选择集合覆盖所有元素，最小化偏好成本。
- **基准方法**：
  - **Direct Answer**：LLM 直接输出方案。
  - **Chain-of-Thought (CoT)**：LLM 逐步推理后输出。
  - **Program-of-Thought (PoT)**：LLM 生成普通 Python 代码（无符号求解器）求解。
  - **MaxSAT-no-plan**：直接生成 MaxSAT 代码（无中间规划）。
  - **MaxSAT-with-plan**：先生成规划，再生成 MaxSAT 代码。
- **LLM 模型**：
  - 闭源：Gemini-3.1-Pro、GPT-5.5
  - 开源：Llama 3.3 (70B)、Qwen-3-Coder (30B)
- **评估指标**：接受率（%）= 通过独立验证（可行且最优）的实例比例。所有方案均通过规范编码验证，而非依赖 LLM 内部报告。

## 6. 论文的主要结论与发现

- **LLM 内部推理不可靠**：Direct Answer 和 CoT 在 MIS 和 Scheduling 上几乎完全失败（接受率 0%~4%），PoT 仅微弱提升。说明 LLM 难以独立解决多约束优化。
- **MaxSAT 编码显著提升可靠性**：MaxSAT-with-plan 方法在 Gemini-3.1-Pro 和 GPT-5.5 上达到 56%~87% 接受率，远超基线。Set Cover 最容易（可超 80%），MIS 和 Scheduling 较难。
- **中间规划有帮助但依赖模型能力**：强模型（Gemini、GPT）从规划中获益（提升约 10~20 个百分点）；弱模型（Llama、Qwen）有时计划会降低性能，表明计划可能引入错误传播。
- **偏好复杂性影响结果**：偏好变体（p1/p2/p3）普遍降低接受率，但 MaxSAT 方法仍远强于基线。某些偏好对某些模型特别困难（如 Qwen 在 p2/p3 上降为 0%）。
- **跨模型规划迁移不一致**：只有当迁移的规划清晰且目标模型能正确实现时才有帮助；整体表现不稳定，尤其对弱模型。

## 7. 优点

- **方法创新性**：首次将 LLM 与偏好 MaxSAT 求解器结合，利用 LLM 生成可执行编码，分离语义理解与形式优化，实现可验证的偏好推理。
- **独立验证机制**：通过规范编码进行可行性 + 最优性双重验证，允许不同编码和多个最优解，避免依赖 LLM 内部报告，评价客观。
- **实验设计严谨**：系统比较多种基线（DA/CoT/PoT），消融规划影响，测试跨模型规划，分析偏好层次效果，统计指标清晰。
- **可扩展性**：方法框架通用，可替换不同 LLM 和 MaxSAT 求解器，易于扩展到其他布尔型优化问题。
- **实用性**：LLM 提供自然语言界面，降低用户使用形式化工具的门槛。
